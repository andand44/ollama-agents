# 01 · Weather Agent

Первый агент в серии. Демонстрирует базовый **tool calling**.

## Что умеет

- `get_current_weather(city)` — погода в городе (заглушка)
- `calculate(expression)` — математические вычисления
- `get_current_time()` — текущее время

## Что демонстрирует

- **Выбор инструмента** — модель сама решает, какую функцию вызвать
- **Множественные вызовы** — за один запрос может вызвать несколько инструментов
- **Sanitizer** — защита от нестабильного формата аргументов
- **Описания в JSON Schema** — как правильно объяснить модели, что делает функция

## Пример вывода

--- Пользователь: Какая погода в Лондоне и Москве? ---
🤖 Вызов: get_current_weather({"city": "Лондон"})
🔧 Результат: Дождь, +12°C
🤖 Вызов: get_current_weather({"city": "Москва"})
🔧 Результат: Облачно, +15°C
🤖 Финальный ответ: В Лондоне сейчас облачно и +15°C.
В Москве +15°C, а облачно.
