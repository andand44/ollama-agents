# 02 · Notes Agent

Агент для работы с заметками. Демонстрирует **работу с файлами** 
и **универсальные санитайзеры**.

## Что умеет

- `save_note(text)` — сохранить заметку в файл `notes.txt`
- `read_notes()` — прочитать все сохранённые заметки

## Что демонстрирует

- **Работа с файлами** через `with open()` — правильное открытие/закрытие
- **Универсальный санитайзер** `sanitize_to_string()` — рекурсивно 
  превращает любой формат (словарь, список, число) в чистую строку
- **Промпт-инжиниринг** — как примеры в описании инструмента учат 
  модель отбрасывать командные слова («Запомни: X» → «X»)

## Пример вывода

--- Пользователь: Запомни: купить молоко ---
🤖 Вызов: save_note({"text": "купить молоко"})
🔧 Результат: Заметка сохранена: купить молоко
🤖 Финальный ответ: Заметка "купить молоко" сохранена.

--- Пользователь: Что я записал? ---
🤖 Вызов: read_notes({})
🔧 Результат: Вот все заметки:
купить молоко
позвонить маме
🤖 Финальный ответ: У вас две заметки: купить молоко и позвонить маме.

## Запуск

python notes_agent.py
