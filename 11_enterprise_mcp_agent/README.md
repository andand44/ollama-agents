# Enterprise AI Assistant (MCP + LangGraph)

Микросервисное решение корпоративного уровня для создания умных ИИ-ассистентов. Проект демонстрирует промышленный подход к построению RAG-систем и агентов с использованием последних стандартов.

## 🏗 Архитектура

Проект развернут в Docker и состоит из 4 независимых сервисов:
- **API (FastAPI + Python 3.15)**: Основной шлюз для приема запросов.
- **PostgreSQL**: Хранение структурированных данных и логов.
- **Redis**: Кэш в оперативной памяти для хранения истории диалога (Memory).
- **Qdrant**: Векторная база данных для семантического поиска (RAG).

## 🚀 Ключевые технологии
- **LangGraph**: Оркестрация агента в виде графа состояний (StateGraph). Реализован цикл ReAct с условными переходами (Conditional Edges).
- **MCP (Model Context Protocol)**: Безопасный стандарт от Anthropic для подключения инструментов. Агент общается с локальными инструментами через отдельный MCP-сервер по stdio, что исключает прямой доступ LLM к файловой системе.
- **LangChain & Ollama**: Использование локальной модели `qwen3.5` и эмбеддингов `nomic-embed-text`.
- **RAG**: Поиск по базе знаний с помощью Qdrant и LangChain.

## 🛠 Что умеет агент
1. Отвечать на вопросы, используя базу знаний (RAG).
2. Запоминать контекст диалога благодаря Redis.
3. Безопасно читать локальные файлы (через MCP-сервер с защитой от Path Traversal).
4. Узнавать текущее системное время (через MCP-сервер).

## 📦 Запуск

1. Убедитесь, что Ollama запущена на хосте и скачаны модели:
```bash
ollama pull qwen3.5:4b
ollama pull nomic-embed-text
```
2. Поднимите инфраструктуру:
```bash
docker compose up -d --build
```
3. API доступен по адресу: http://localhost:8001/docs

## 🧪 Тестирование

1. Добавьте факт в базу знаний: POST /add_knowledge

2. Спросите агента: POST /chat

3. Попросите прочитать файл test.txt из папки safe_data (предварительно создав его).
