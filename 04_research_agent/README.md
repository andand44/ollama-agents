# 04 · Research Agent с верификацией фактов

Самый продвинутый агент в серии. Ищет в интернете, читает страницы 
и **проверяет факты** по нескольким источникам. Борется с галлюцинациями.

## Что умеет

- `search_web(query)` — поиск через ddgs (DuckDuckGo, Bing, Google)
- `fetch_wikipedia(query)` — краткая статья из Wikipedia
- `fetch_page(url)` — загрузка полного содержимого страницы

## 🎯 Ключевая фича: борьба с галлюцинациями

Маленькая модель (3B) **выдумывает факты**, если спрашивать её «из памяти». 
Этот агент **не доверяет памяти** — он заставляет модель:

1. Найти ссылки через `search_web`
2. Открыть 1-2 страницы через `fetch_page`
3. Сверить факты из разных источников
4. Ответить только тем, что подтверждено

### Демонстрация: до и после верификации

**До верификации** (модель отвечает из памяти):
> Вопрос: *«Какие фильмы про Трансформеров существуют?»*  
> Ответ: *«Первый фильм вышел в 1989 году. Также: "Новый эльфийский мир"»* ❌

**После верификации** (агент читает Wikipedia):
> Вопрос: *«Какие фильмы про Трансформеров существуют?»*  
> Агент: `search_web("Трансформеры фильмы")` → `fetch_page(wikipedia)`  
> Ответ: *«Первый фильм — 2007 год»* ✅
