# 03 · Calculator Agent

Калькулятор с **памятью переменных**. Демонстрирует **agentic loop** — 
многошаговый цикл, в котором модель может вызывать инструменты подряд.

## Что умеет

- `calculate(expression)` — вычислить выражение (с подстановкой переменных)
- `save_variable(name, value)` — сохранить результат под именем
- `get_variable(name)` — получить значение переменной
- `list_variables()` — показать все переменные

## Ключевая фича: подстановка переменных

Функция `calculate()` **сама подставляет** значения из `MEMORY` 
перед вычислением. Поэтому модель может писать:
calculate("total + 100") → calculate("60 + 100") → 160

даже если модель «не знает», что `total = 60`. Это решает проблему 
изоляции инструментов: они не видят друг друга напрямую.

## Что демонстрирует

- **Agentic loop** — цикл `while`, пока модель запрашивает инструменты
- **Общая память (MEMORY)** — глобальный словарь между инструментами
- **`**kwargs` распаковка** — `func(**arguments)` вызывает функцию по имени
- **Словарь инструментов** — `TOOL_FUNCTIONS` как switch-case
- **Защита от зацикливания** — `MAX_ITERATIONS = 10`

## Пример вывода

--- Пользователь: Посчитай 2 + 2, сохрани как a. Посчитай 3 + 3,
сохрани как b. Посчитай a + b ---
[LOOP] Инструмент #1: calculate({"expression": "2 + 2"}) → 4
[LOOP] Инструмент #2: save_variable({"name": "a", "value": "4"})
[LOOP] Инструмент #3: calculate({"expression": "3 + 3"}) → 6
[LOOP] Инструмент #4: save_variable({"name": "b", "value": "6"})
[LOOP] Инструмент #5: calculate({"expression": "a + b"}) → 4 + 6 → 10
🤖 Финальный ответ: Результат: 10

## Запуск

python calc_agent.py
