# 05 · Multi-Agent Text Editor

Мультиагентная система редактирования текстов на локальной LLM. 
**4 AI-агента** работают последовательно: Критик → Редактор → Факт-чекер → Судья.

![Multi-Agent Editor demo](../assets/05_multiagent_demo.gif)

## 🎯 Что делает

Пользователь вставляет текст → система прогоняет его через 4 агента → 
возвращает улучшенный текст с пояснениями на каждом шаге.

## 🏗️ Архитектура

Текст ─→ [Критик] ─→ замечания
↓
[Редактор] ─→ JSON-правки (diff)
↓
[Факт-чекер] ─→ проверка через интернет
↓
[Судья] ─→ финальный вердикт

## 🧠 Ключевая фича: diff-подход

**Проблема:** если дать LLM переписать текст целиком — она **удалит факты** 
(числа, проценты, даты), оставив общие фразы.

**Решение:** Редактор возвращает **список правок** в формате JSON:

```json
[
  {"before": "очень важно отметить, что", "after": ""},
  {"before": "играют очень важную роль", "after": "важны"}
]
